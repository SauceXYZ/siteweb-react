# Portfolio Next.js

1. Installer : `npm install`
2. Lancer en local : `npm run dev` (ouvre http://localhost:3000)
3. Modifier les textes : `app/page.js`, objet `content` tout en haut
4. Couleurs et dégradés : `app/globals.css`
5. Mettre en ligne : le plus simple est Vercel (importe le dossier), ou `npm run build` puis `npm start`
